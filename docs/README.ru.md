# VK Comment Manager: подробная инструкция для всех пользователей

## Что делает программа

VKCM запускается **на вашем компьютере**, открывает локальную страницу интерфейса и читает скачанный **вами** архив своих данных VK. Показывает комментарии и позволяет после подтверждения попытаться удалить собственные комментарии к записям, включая несколько собственных ответов в одной ветке. **Не является официальным клиентом VK.**

## Быстрая установка (Mac / Linux)

Нужно установить Git. Подходящий Python 3.10+ программа найдёт сама, а на Mac при необходимости предложит установить Python 3.13 через Homebrew. Системный Python 3.9 не меняется. Если Homebrew нет, программа покажет официальную страницу установки Python. В Терминале:

```bash
git clone https://github.com/Nelect96/vk-comment-cleaner.git
cd vk-comment-cleaner
bash scripts/app.sh
```

Меню само установит отдельное локальное окружение Python и Chromium при первом запуске, затем предложит открыть интерфейс, выбрать архив для удаления или проверить тесты. Браузерная программа открывается по адресу `http://127.0.0.1:18765`. Windows пока требует WSL/Bash. **Не запускайте программу на удалённом публичном сервере** и не открывайте порт наружу.

Это инструкции для будущего публичного релиза. Пока приватный репозиторий доступен только участникам проекта.

## Язык интерфейса

Веб-интерфейс поддерживает **русский и английский**. По умолчанию язык выбирается по настройке браузера; переключатель **Language** расположен в шапке. Выбор сохраняется локально. В Терминале все команды подтверждения английские: `DELETE BATCH N`, `STOP`, `CONFIRM DELETED ID` и `DELETE` для необязательных действий VK API. Русская раскладка для ввода команд не нужна.

## Шаг 1. Запросите свой архив данных VK

1. Авторизуйтесь на официальном сайте VK.
2. Откройте [раздел защиты данных](https://vk.com/data_protection?section=rules). Если VK изменил адрес, найдите «Защита данных» / «Запросить архив» через настройки своего аккаунта.
3. Выберите экспорт данных, отметьте категорию **«Комментарии»** (название может отличаться в текущем интерфейсе), отправьте заявку. При необходимости пройдите подтверждение личности на сайте VK.
4. Когда VK предложит скачать готовый архив, скачайте ZIP на компьютер. Не распаковывайте его без необходимости; в архиве могут находиться личные данные.
5. В VK Comment Manager нажмите импорт архива и укажите ZIP (или используйте поиск в Downloads на Mac). Убедитесь, что программа распознала комментарии.

Программа **не может** за вас заказать и скачать защищённый архив VK. Пароли и ZIP никогда не отправляйте в issue на GitHub.

## Шаг 2. Войдите через VK ID

Для входа требуется **ваше** VK ID приложение. Создайте его через [официальный кабинет VK ID](https://id.vk.ru/), сохраните App ID и зарегистрируйте Redirect URL. Используйте эти значения в локальном интерфейсе. Для loopback callback укажите `http://127.0.0.1:18765/oauth/callback` **только если VK разрешает регистрировать HTTP-адрес**. Если VK принимает только HTTPS, потребуется зарегистрировать ваш собственный HTTPS URL и затем вставить полный URL ответа в локальное поле «Завершить вход по URL»; не делитесь им.

Пользовательский App ID не является секретом, но никто не должен использовать чужой App ID без разрешения. Не вводите пароль VK в сторонних формах; официальный экран входа должен находиться на `id.vk.ru`. Войти в VK ID и войти в Chromium для работы на страницах VK иногда нужно отдельно. Доступ к методам старого VK API может быть запрещён (например, код ошибки 1051), но браузерный режим работает независимо от этих методов.

## Шаг 3. Проверьте записи

В локальном интерфейсе доступны поиск и фильтрация импортированных комментариев, переход к исходному обсуждению и экспорт списка в CSV. Просмотр поддерживает ссылки к стене, фото и видео. **Пакетное браузерное удаление пока работает только с комментариями под записями на стене.**

## Шаг 4. Автоматическое удаление собственных комментариев

Закройте предыдущий сервер или процесс VKCM, затем:

```bash
cd vk-comment-cleaner
bash scripts/cleanup.sh "/полный/путь/к/вашему/Archive.zip"
```

Программа попросит войти через VK ID, проверит пользователя, составит пакет максимум из 1000 ещё не обработанных записей и попросит ввести **точную английскую** фразу `DELETE BATCH N` с показанным количеством. При необходимости для выхода вводите `STOP`; подтверждение уже удалённого комментария выполняется как `CONFIRM DELETED 123` (с соответствующим ID). Русская раскладка не нужна. До подтверждения кнопки удаления не нажимаются. Затем откроется отдельный Chromium. Если нужно, войдите в свой аккаунт VK и дождитесь проверки.

Перед каждым удалением программа ищет **точный идентификатор** комментария, отдельно проверяет, что автором является ваш VK ID, и проверяет кнопку удаления внутри соответствующего элемента. Если проверка неоднозначна, операция пропускается или останавливается. Несколько ваших ответов на одном посте группируются; вложенные ответы по возможности обрабатываются раньше основной реплики. Чужие комментарии удалять запрещено.

Состояние каждой операции пишется в локальный журнал **перед** кликом. После остановки можно запустить ту же команду с тем же архивом, ранее обработанные записи и неопределённые исходы не будут повторно удаляться. Повторный поиск отсутствовавших комментариев доступен только отдельной осознанной операцией для статуса `browser_not_found`; не обходите блокировку неопределённых исходов.

### Результаты и ограничения

- `browser_ui_deleted_marker`: интерфейс VK показал признак удаления, но это **не серверное подтверждение**.
- `browser_not_found`: комментарий не был найден **до** клика.
- `browser_unknown`: клик мог произойти, но итог неизвестен; повторять его нельзя.
- Смена HTML-разметки VK, приватные/удалённые записи, скрытые ответы, блокировки и капчи могут помешать поиску. Программа не пытается их обходить.
- Чтобы остановить автоматическую очередь, нажмите `Ctrl+C`.

## Где хранятся данные

ZIP импортируется в локальный процесс. Журнал сохраняет VK ID, идентификаторы комментариев и состояния операций. Chromium хранит отдельный локальный профиль авторизации; удалите его через системные средства, если больше не используете программу. Данные не отправляются автору приложения и не публикуются в GitHub. Не выкладывайте в issues архивы, журналы SQLite, cookies, OAuth URL и токены.

## Устранение проблем

Если порт `18765` занят, задайте свой порт командой `export VKCM_PORT=18766` перед запуском и используйте точно тот же порт при настройке локального OAuth callback, если VK его разрешает. Не закрывайте незнакомые процессы на порту. Если тесты не прошли, **не запускайте удаление**, приложите только обезличенную ошибку.

Для разработчиков: `.venv/bin/python -m unittest discover -s tests -q`. Публикация новой версии описана в [PUBLISHING.md](PUBLISHING.md).
