# Changelog

## 0.4.0 — Public release candidate (October 2026)

- Local-first archive browsing and batch deletion of **the signed-in user's own** wall comments.
- Group archived replies by their parent post; process own nested replies before matching roots.
- Journal every attempted click, including uncertain outcomes, to prevent blind retries.
- Isolated Chromium session and local web interface; no public server or archive uploads.
- Own VK ID App ID and registered callback required; no third-party account defaults.
- Simplified macOS/Linux setup and English/Russian guides.
- User archive must be explicitly selected; deletion requires authenticated identity and confirmation.
- Independent VK project, not an official VK application.

> Notes about private development sessions, account identifiers, and personal infrastructure are intentionally omitted from the redistributable changelog. They remain in the original private development history, which must **not** be made public.
